# 课程大纲（项目线 × 知识线）

> 状态：**已审定（2026-10-24，五个决策点定案，见文末"审定记录"）**，本文件为课程正式目录。
> 结构：第一层 = **项目迭代线**（v1~v11，对应 PRD 迭代清单）；第二层 = 每个迭代下挂的**知识单元**（U1~U45）。
> 单元因项目需要而被学，学完立刻用于项目。

## 使用说明

- 单元编号全局唯一（与纪要中 U7~U9 = 向量化/分块/向量库 的引用保持一致）。编号是**知识地图**，不是严格学习顺序——学习顺序按项目需求驱动，大体沿编号走、允许跳跃（当前入口见文末）。
- 每个单元文档固定结构：学习目标 / 前置知识 / 概念讲解 / 常见误区 / 动手实验（填空式）/ 自测清单 / 单元小结（留白由用户写）。
- 每个单元走四阶段闭环：① 知识输入 → ② 理解（预测题）→ ③ 实操（填空）→ ④ 巩固（费曼小结），缺一不可。
- 实操分工：**知识核心**（RAG 原理、Agent 循环、prompt 设计）用户写、AI review；**工程粘合**（接口接线、文件 IO、配置）AI 写、用户读。
- 标 ★ 的单元是纪要 §5 知识查漏补全项（用户未主动提及、岗位技术链路必需）。
- 状态标记：✅ 已完成 / 🔶 部分完成 / ⬜ 未开始。

## 审定记录（2026-10-24 定案）

1. **单元粒度**：保持 45 个单元（v1 占 14 个），小而完整、闭环快、进度感强。
2. **U28 LangGraph**：纳入，定位为"痛点驱动的重构"——v4 先手写 Agent 循环，以并行生成/失败回环/断点续跑三个真实痛点引入重构；深度视项目实际形态调整，需求撑不起来则降级为认知内容。
3. **护栏时机**：U6/U10 单元含 prompt injection 认知误区提示，U38 深入。
4. **U17 前端速览**：保留，作 Vue3 前的过渡。
5. **学习入口**：U6 开局，U7→U8→U9→U10 闭环后改造搁置的 rag_engine.py；U1/U2 残余随用随补；U3/U4 在项目第 4 步（内容生成）前学。
