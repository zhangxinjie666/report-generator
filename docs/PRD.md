# 产品说明文档 (PRD)

## 1. 项目概述

### 1.1 项目名称
实验报告智能生成系统 (Report Generator)

### 1.2 项目目的
通过一个有真实需求的项目来学习 AI 全栈开发技术，让所学知识能解决实际问题。项目设计服务于学习需求，贴合企业真实生产场景。

### 1.3 目标用户
- 第一版：仅开发者本人使用
- 后续迭代：支持多用户

### 1.4 项目定位
- 第一版：电工电子实验报告自动生成工具
- 最终形态：支持任意类型报告的 AI 生成平台

---

## 2. 第一版功能定义

### 2.1 核心价值
用户传入实验相关材料，系统自动生成符合课程要求的实验报告，免去手动排版和撰写文字的重复劳动。

### 2.2 输入
| 输入项 | 格式 | 说明 |
|---|---|---|
| 实验内容 | 文本 | 实验的文字描述（实验目的、原理要点、步骤等原始要求） |
| 原始数据 | 结构化数据 (CSV/JSON) | 实验测量数据（用户先用外部工具将手写表格转为结构化数据） |
| 报告模板 | docx | 学校提供的实验报告模板，含封面、章节结构、表格样式 |
| 参考报告 | PDF (1-2 份) | 已完成的优秀报告，作为内容和格式的参考 |
| 生成要求 | 文本 | 特殊要求（如"仿真验证实验，无需填写实测值"） |

### 2.3 输出
| 输出项 | 格式 | 说明 |
|---|---|---|
| 实验报告 | docx | 可编辑的完整报告 |
| 实验报告 | PDF | 最终交付格式 |

### 2.4 核心流程
```
[输入材料]
    ↓
[1] 解析报告模板 → 识别封面字段、章节结构、表格格式
    ↓
[2] 参考报告向量化 → RAG 知识库
    ↓
[3] 检索相似实验写法 → 作为 LLM 生成上下文
    ↓
[4] LLM 生成各章节文字 → 结构化输出（目的/原理/步骤/结果分析/讨论）
    ↓
[5] 数据校验 Hook → 检查 KCL/KVL 等定律约束是否满足
    ↓
[6] 组装 → 数据填表格、文字填章节、插图
    ↓
[7] 导出 docx → 转 PDF
```

### 2.5 第一版不做的功能
- 数据处理与工具调用 — 第二版
- 多模态（图片转表格）— 第三版
- 对话式修改 + 版本管理 + 评审 Agent — 第四版
- 前端界面 — 第五版
- Agent 自主编排 — 第六版（第一版用规则编排）
- 数据库与历史记录 — 第七版
- 多用户与鉴权 — 第八版
- 任意报告类型适配 — 第十版

## 3. 功能模块划分（第一版）

| 模块 | 职责 | 对应技术 |
|---|---|---|
| 模板解析 | 读取 docx，识别封面字段位置、章节结构、表格行列 | python-docx |
| RAG 知识库 | 参考报告 PDF 切块、embedding、存入 Chroma | LangChain + Chroma |
| 内容生成 | 基于实验内容 + 检索结果，LLM 生成各章节文字 | LangChain + LLM |
| 数据校验 | 生成后自动校验实验定律约束 | Hook 机制 |
| 报告组装 | 将文字和数据填入模板 | python-docx |
| 导出 | docx 转 PDF | Word COM / LibreOffice |

---

## 4. 非功能需求

| 维度 | 要求 |
|---|---|
| 可运行性 | 本地一键启动，开发调试友好 |
| 可维护性 | 模块分层清晰，便于后续迭代升级 |
| 可扩展性 | 预留 Agent 化、多模态、多用户的扩展点 |
| 成本 | 第一版使用免费 LLM 和本地 embedding，零运行成本 |
| 量化诚信 | 一切写上简历/文档的量化指标必须有对应评测实验支撑，禁止无评测数字 |

## 5. 后续迭代路线图

| 版本 | 功能 | 学习重点 |
|---|---|---|
| v1 (MVP) | 规则编排 + RAG + 生成 + 导出 | LLM 结构化输出、RAG 全流程、文档处理、Hook |
| v1.x | 专业语料扩展 + 最小评测集 | 标注对构建、检索质量量化验收 |
| v2 | 数据处理与工具调用 | Tool Use、代码执行、pandas/numpy、matplotlib |
| v3 | 多模态（VLM 识别手写表格） | VLM API、结构化输出 prompt |
| v4 | 对话式修改 + 版本管理 + 评审 Agent | 会话管理、增量修改、评审与生成分离 |
| v5 | 前端界面 | Vue3、Element Plus、SSE 流式展示 |
| v6 | Agent 化编排（含独立评审闭环） | Agent 循环、规划、记忆、LangGraph 痛点重构 |
| v7 | 数据库 + 历史记录 | SQLAlchemy、数据建模 |
| v8 | 多用户 + 鉴权 | JWT、中间件、权限控制 |
| v9 | 工程化补齐 | 日志、测试、缓存、限流 |
| v10 | 任意报告类型适配 | 模板动态适配 |
| v11 | 评估体系 | 输出评测、检索质量评估 |
| v12 | 部署上线 | Docker、运维基础 |
